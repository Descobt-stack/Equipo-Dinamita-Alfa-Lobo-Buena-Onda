# TÍTULO FUTURO · Equipo de trabajo

Portafolio profesional de un equipo formado por dirección de ideas creativas, marketing e ingeniería de software.

## Cómo participar sin editar código

La página incluye tres botones de propuesta:

- **Actualizar mi trayectoria:** para experiencia, formación, habilidades o logros profesionales.
- **Proponer proyecto:** para una aplicación, servicio o colaboración nueva.
- **Compartir idea:** para una mejora, comentario o propuesta del equipo.

Cada botón abre una propuesta guiada en GitHub. Las propuestas se revisan antes de integrarse a la página.

> No agregues teléfonos, correos, direcciones, contraseñas, documentos personales ni información confidencial en las propuestas públicas.

## Estructura

- `index.html`: página principal.
- `team-data.js`: resumen del equipo y proyectos.
- `perfiles/`: trayectorias profesionales individuales.
- `.github/ISSUE_TEMPLATE/`: formularios para proponer cambios sin tocar código.

## Publicar con GitHub Pages

En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
