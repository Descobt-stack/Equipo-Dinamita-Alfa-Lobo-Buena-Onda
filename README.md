# TÍTULO FUTURO

> Ideas con dirección. Marca con sentido. Software que funciona.

Somos un equipo de trabajo que une creatividad, marketing e ingeniería de software para convertir necesidades reales en productos claros, útiles y sostenibles.

---

## Un equipo, tres direcciones

| Área | En qué aporta |
| --- | --- |
| **Dirección de ideas creativas** | Da rumbo a la idea, organiza prioridades y aporta una visión administrativa y financiera. |
| **Marketing y comunicación** | Define audiencia, marca, contenido y la manera en que un producto puede conectar con las personas. |
| **Ingeniería de software** | Diseña, desarrolla, prueba y mejora la parte funcional de cada producto. |

La fuerza del equipo está en que cada propuesta se mira desde las tres perspectivas antes de avanzar.

## Proyecto en desarrollo

### Mi Libreta Financiera

Nuestro primer proyecto es una aplicación para ayudar a las personas a registrar y entender mejor sus gastos e ingresos.

Actualmente se encuentra en etapa de desarrollo y pruebas. La página del equipo reúne el enfoque, los aportes de cada perfil y los próximos proyectos que iremos publicando.

---

## Participa sin programar

Cada integrante puede compartir cambios o propuestas desde GitHub sin modificar código:

| Botón | Para qué sirve |
| --- | --- |
| **Actualizar mi trayectoria** | Proponer cambios de experiencia, formación, habilidades o logros profesionales. |
| **Proponer proyecto** | Compartir una aplicación, servicio o colaboración nueva. |
| **Compartir idea** | Sugerir una mejora, comentario o propuesta para el equipo. |

Las propuestas se revisan en conjunto antes de integrarse a la página pública.

> **Privacidad primero:** no agregues teléfonos, correos, direcciones, contraseñas, documentos personales, datos de clientes ni información confidencial en propuestas, proyectos o archivos públicos.

## Contenido del repositorio

| Archivo o carpeta | Función |
| --- | --- |
| `index.html` | Página principal del equipo. |
| `team-data.js` | Información pública del equipo y proyectos. |
| `perfiles/` | Perfiles profesionales individuales. |
| `assets/` | Recursos visuales usados por la página. |

## Publicación

La página se publica con **GitHub Pages** desde la rama `main` y la carpeta `/(root)`.

Cuando el equipo tenga un proyecto nuevo o una actualización aprobada, se podrá añadir aquí de manera ordenada y segura.
